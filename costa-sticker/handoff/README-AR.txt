================================================
   عدة الشغل — ستيكر COSTA 5W-30 (5L)
   جهزلي كل شي، افتح وكمّل 🚀
================================================

【 قبل ما تفتح أي برنامج 】
1) نصّب الخطوط من مجلد fonts (دبل كليك > Install):
   - RussoOne-400.ttf      ← خط اللوغو و 5W-30 و 5L و ENGINE OIL
   - Montserrat-500/600/800 ← LUBRICANT والنصوص الصغيرة
   - Lora-Bold.ttf          ← كلمة BEST بالختم

【 أفضل طريقة تشتغل 】
▶ إليستريتور (أو Inkscape المجاني أو Photopea من المتصفح):
   افتح: COSTA-label-editable.svg
   - كل شي جاهز طبقات: الخلفية الأصلية + كل النصوص قابلة للتعديل
   - مقاس العمل: 1000×1425 وحدة = 100×142.5 ملم للطباعة
   - عدّل أي نص/موقع بعينك، وبعدها:
     File > Save As > PDF (اختار High Quality Print)

▶ إذا فوتوشوب:
   افتح COSTA-5W30-5L-sticker-3000px.png كطبقة أساس
   و label_full.png (الخلفية الأصلية مقصوصة) وركّب فوقها النصوص
   بالخطوط المذكورة والقياسات تحت.

【 الأصول الجاهزة بالمجلد 】
- reference.jpg          الصورة الأصلية للمقارنة
- label_full.png         خلفية الستيكر كاملة (من الصورة الأصلية، منظفة من النصوص)
- engine_crop.png        صورة المحرك مقصوصة دائرية
- splash_crop.png        رشة الزيت مفرغة بخلفية شفافة

【 الألوان (Hex) 】
- ذهبي اللوغو (تدرج):   #FDF6DC → #E9C86C → #A87B22
- حد اللوغو:             #7A5716
- كحلي غامق:             #212A63 → #273176
- أزرق ملكي:             #24409A
- أزرق فاتح (الإسفين):   #3A7DC0 → #4C93D6
- كريمي النصوص:          #F2E8C0 / #F0E8D0
- كحلي الختم:            #16264F
- أحمر العلم:            #D5121E   أصفر العلم: #F7C500

【 القياسات (بوحدات ملف الـ SVG، 10 وحدات = 1 ملم) 】
- COSTA: خط Russo One حجم 101، تباعد أحرف 22.5، الوسط x=484، خط القاعدة y=329
- LUBRICANT: Montserrat Medium 16، تباعد 19، y=381
- ENGINE OIL: Russo One 55، تباعد 9، الوسط x=376، y=582
- SYNTHETIC: Russo One 33، تباعد 13، يبدأ x=481، y=943
- 5W-30: Russo One 82، تباعد 15.5، يبدأ x=480، y=1064
- API SP: Russo One 40، يبدأ x=489، y=1151
- 5L: Russo One 99 (مشدود أفقيًا 1.23)، y=1397
- الختم: مركز (850,743)، قطر خارجي ~222
- شعار ألمانيا: مركز العلم (728,1342)
