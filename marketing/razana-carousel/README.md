# الرزانة — كاروسيل «قصة زبون ما دفع»

كاروسيل إنستغرام من 7 سلايدات لشركة **AL RAZANA** (مطابخ تجارية). الفكرة: بوست يبدأ
كأنه فضح علني لزبون استلم مطبخ مطعم كامل وما دفع، وكل سلايد «دليل» على خدمة قدّمناها له —
وبالسلايد الأخير ينكشف إن الزبون متخيّل والخدمات حقيقية.

## المخرجات

`final/razana-01.png` … `final/razana-07.png` — مقاس **1080×1350** (4:5)، جاهزة للنشر.

## بنية الكاروسيل

| # | النوع | المحتوى |
|---|---|---|
| 1 | غامق | الهوك — بطاقة اسم العميل بكنية مشطوبة + ختم «غير مسدّد» |
| 2 | فاتح | الدليل 01 — التصميم والاستشارة |

| 4 | فاتح | الدليل 03 — التصنيع |

السلايدات الغامقة تفتح وتقفل الكاروسيل، والخمسة الفاتحة بينهم — إيقاع بصري مقصود.
كل سلايد دليل ينتهي بختم `استلم ✓ / دفع ✗` يتراكم لحد الكشف.

## ملاحظات نشر

- **انشر السلايدات السبعة كاملة.** لو انتشر سلايد لحاله بستوري بدون سلايد الكشف،
  بيتقرأ كاتهام حقيقي لشخص.
- «خالد» اسم متخيّل — تأكد إنه ما يطابق أي عميل حقيقي.
- **رقم التواصل بالسلايد 7 لسه placeholder** (`+971 50 000 0000`). لازم يتغيّر قبل النشر.

## إعادة التوليد بعد أي تعديل

```bash
npm i playwright          # الكروميوم لازم يكون منصّب
node render.js            # يطلّع out/razana-01..07.png بمقاس 2160×2700
```

بعدها صغّرهم لـ 1080×1350 (المصدر برندر على 2x عشان جودة أعلى بعد التصغير).

الملفات: `slides.html` (التصميم كامل)، `render.js` (الرندر)، `fonts/` (الخطوط محلياً)،
`logo.png` + `logo-white.png` (اللوجو بخلفية شفافة، ملوّن وأبيض).
