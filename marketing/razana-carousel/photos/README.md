# صور المشاريع الحقيقية

حط هنا 5 صور من مشاريعكم وبتحل تلقائياً مكان الرسم الهندسي بكل سلايد:

| الملف | السلايد | المحتوى المقترح |
|---|---|---|
| `01-design.jpg` | التصميم | مخطط مطبخ أو تصميم 3D |
| `02-supply.jpg` | التوريد | معدات واصلة / مستودع |
| `03-fabricate.jpg` | التصنيع | تصنيع الستانلس بالمصنع |
| `04-install.jpg` | التركيب | الفريق داخل مطبخ قيد التركيب |
| `05-service.jpg` | الصيانة | فني صيانة أو قطع غيار |

المقاس المفضّل: 1800×928 أو أكبر (عرضي). بعد إضافة الصور شغّل `node render.js`.
